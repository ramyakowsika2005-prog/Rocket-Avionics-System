# Hardware

This folder contains the hardware components used in the Rocket Avionics System.

## Main Components

- ESP32 Development Board
- TeleMega Flight Control Computer (C-FCC)
- BMP390 Pressure Sensor
- MPU9250 IMU Sensor
- Neo-8M GPS Module
- LoRa SX1278 Transceiver
- RTC Module
- Power Distribution Board
- Battery
- Ignition Circuit

These components form the Indigenous Flight Control Computer (I-FCC) and Commercial Flight Control Computer (C-FCC) architecture used in the TEKNOFEST Rocket Competition project.
